# 💳 Pricing Cards UI

A modern and responsive Pricing Cards UI built using **HTML** and **CSS**.
This project focuses on clean UI design, responsive layouts, reusable CSS variables, hover animations, and modern card components.

## ✨ Features

* Responsive pricing cards layout
* Modern dark UI design
* CSS Grid responsive system
* Smooth hover animations
* Highlighted popular plan
* Reusable CSS variables
* Testimonial section
* Mobile responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Font Awesome
* Google Fonts
